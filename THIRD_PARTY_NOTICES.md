Their MIT license covers those instructions, not the hosted service, voice identities, or generated recordings. Keep each recording's provenance and applicable plan/service rights with its project; Mashhad's MIT license does not automatically apply to it. See [ElevenLabs' publication guidance](https://help.elevenlabs.io/hc/en-us/articles/13313564601361-Can-I-publish-the-content-I-generate-on-the-platform).
- **Thmanyah Sans:** the official license permits personal and commercial design uses. The font files are not included in this repository or its source downloads. Obtain them from [Thmanyah’s official page](https://font.thmanyah.com/) and supply a local font path. The license prohibits redistributing or independently exposing the font files and restricting them is not removed by Mashhad’s MIT license. See the [authoritative Arabic license](https://font.thmanyah.com/licenses). Rendered typography does not transfer font ownership.
- **Remotion:** the runtime has a custom license with a free tier for specified eligible entities and a company license for others. The official skills repository had no root license and its inspected package/frontmatter did not declare one; this release only links to it. Do not infer a blanket MIT grant for that repository.
- **GSAP:** the skill package is MIT; the runtime has Webflow’s separate Standard No Charge license, including restrictions concerning competing visual animation builders.
- **Rendervid:** the custom FlowHunt Attribution License requires visible attribution for projects using the software. Merely crediting a surveyed optional renderer here is not evidence that a delivered film used it; apply its exact terms when it actually runs.
- **Proprietary Arabic pack:** Mamdouh Aboammar’s motion-graphics-skills pack is excluded. None of its instructions, code, architecture, assets or films is incorporated. Its current license is recorded only to explain that boundary.
- **Adobe After Effects, Blender and Rive:** optional editors/services remain separately obtained. Bridge or runtime licenses do not grant licenses for commercial editors, hosted exports, downloaded models, or community animation assets. Inspect the selected product and assets before use.
- **Future reuse:** when adding upstream code or assets, record exact files, revision, changes and applicable notices; preserve required license texts. Recheck the selected version rather than treating this dated inventory as a permanent grant.
