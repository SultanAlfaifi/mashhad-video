# Evaluation of Mashhad

Use this when creating or materially changing the skill. Keep ordinary video production focused on its deliverable.

## Two kinds of validation

Package checks establish valid metadata, reachable local references, valid manifests, and functioning helpers. Behavioral evaluation establishes whether the agent selects and executes an appropriate workflow. Neither alone proves superior aesthetic results.

Use [evaluation-cases.json](evaluation-cases.json) as a starting set. Give an independent agent one realistic prompt, the skill path, and minimum raw artifacts. Keep expected outcomes from that agent; evaluate its actual artifacts/actions afterward. Bound side effects, time, and provider cost. A no-render routing case must be recorded as a routing case, not a completed film.

## Compare against a baseline

For visual quality, run the same brief/assets/output constraints with and without the skill using the same model, runtime versions, and comparable time budget. Randomize viewing order. Ask reviewers to compare message clarity, legibility, timing/continuity, art-direction consistency, audio fit, and editability. Record rationale and defects, not just a combined numerical score. Multiple distinct briefs are needed before claiming a general improvement.

Observe latency, render attempts, human corrections, crashes, wrong-engine choices, unnecessary setup/approval questions, accidental scope expansion, and claims unsupported by media evidence. An impressive single demo is not proof of being the best skill.

## Important cases

- Explicit engine/format and existing source are preserved.
- Arabic shaping and Latin numerals remain readable throughout motion.
- A small text fix stays local instead of triggering a full redesign.
- A specialist engine exports a short sample that the primary compositor imports correctly.
- Missing tools and unapproved paid providers do not result in invented success.
- Restricted third-party material stays outside the package.
- A failed ffmpeg command, corrupt media, or wrong frame count cannot be reported as passing.
- Paused work remains paused; resuming uses verified checkpoints.
- A generic website CSS request does not activate the video pipeline.

Keep raw results and the evaluation date in the development workspace, not in every future model's prompt. Fix the demonstrated failure at its source and rerun the affected cases. Avoid accumulating unrelated universal instructions.
